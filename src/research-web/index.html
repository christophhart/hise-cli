HISE Research Assistant

This local research tool uses the worker and thinker models configured in hise-cli to search HISE documentation, examples and code snippets and produce a sourced answer.

It presents its findings with code examples and links to relevant sources so you can dig deeper if needed. In order to prevent hallucinations and bad code syntax, the website can call your locally running HISE instance and run a diagnostic pass on every generated code example.
