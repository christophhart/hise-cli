# Local research server

`hise-cli --research-server` starts a loopback-only browser interface for sourced
HISE documentation research. It is the first-class bring-your-own-model frontend:
provider credentials and worker/thinker selection remain in hise-cli's Pi settings
under `~/.hise/agent` and are never sent to the browser.

## Usage

```bash
hise-cli --research-server
hise-cli --research-server --port 4410 --no-open
```

Configure thinker and worker models through `/ai` and provider authentication
through `/login` before starting the server.

Optional environment variables:

```text
HISE_RESEARCH_AGENT_DIR
HISE_RESEARCH_DOCS_URL
HISE_RESEARCH_SITE_URL
```

The documentation service defaults to `http://localhost:4406`; canonical links
default to `http://localhost:4401`.

## Request flow

The server reloads current Pi settings for each request, checks the documentation
service, expands the question with the worker, performs bounded MCP retrieval,
reranks candidates with the worker, and retrieves selected evidence. Answer mode
then synthesizes with the thinker. Source-only mode stops before synthesis and
returns the selected evidence table.

Optional HiseScript validation remains an explicit browser-controlled phase. The
browser checks local HISE and submits generated code to `/api/diagnose_script`;
the server performs a bounded evidence-preserving correction when diagnostics fail.

## Boundaries and security

- The server binds to `127.0.0.1` only.
- Provider credentials and Pi sessions remain server-side.
- Host, origin, and per-process request-token checks protect API routes.
- Research concurrency and request body size are bounded.
- Browser assets are embedded into the main bundle; no runtime asset directory is
  required by a standalone binary.
- Markdown HTML is generated by the server with raw model HTML removed and links
  restricted to safe protocols.

The research server lives in `src/research-server/`; its browser document lives in
`src/research-web/`. Retrieval and HiseScript guidance shared with the CLI remain
in `src/engine/docs-assistant/`.
